# Cartzy (static demo)

Online storefront builder with streamlined checkout. Merchants launch and manage a digital shop; customers browse and pay through a short checkout.

Vite + React + localStorage — no MERN/PHP/WordPress backend.

## Preview

```bash
npm install
npm run dev
```

Open http://localhost:2140
